One line about office life, under 200 characters — a reply-all joke with the
punchline built into the irony: asking everyone to stop replying-all, and
everyone agreeing by replying-all.

Run `python3 main.py`; it writes the joke to `/output/entry.txt` (stdlib only,
no network).
